# MCGC Discipleship Portal

## Project Overview

The MCGC Discipleship Portal is a modern Learning Management System (LMS) developed for the Ministry of Christ's Great Commission Church (MCGC).

The purpose of the system is to guide students through structured discipleship courses, monitor spiritual growth, administer assessments, and issue certificates upon successful completion.

---

## Vision

Build a simple, beautiful, and maintainable discipleship platform that can eventually be used by other churches.

---

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
- Git & GitHub

---

## User Roles

### Student
- View courses
- Study lessons
- Take final exams
- View progress
- Download certificates

### Teacher
- Review essay answers
- Recommend certificate approval

### Admin
- Manage users
- Manage courses
- Manage lessons
- Manage exams
- Approve certificates
- View reports
